## 🎯 רכיבים עיקריים

### 1. סקריפט ההתקנה (AntiPorn)

**מטרה**: לאפשר התקנה אוטומטית או ידנית של קובץ HOSTS.

**תכונות**:
- ממשק משתמש טקסטואלי
- גיבוי אוטומטי של hosts קיים
- התקנה אוטומטית או ידנית
- תמיכה ב-Linux, macOS, Windows

**טכנולוגיה**: Shell Script (sh/bash)

### 2. קובץ HOSTS (PornHosts)

**מטרה**: רשימה מקיפה של אתרים לחסימה.

**פורמט**: 
```
0.0.0.0 example.com
0.0.0.0 www.example.com
```

**גודל**: עשרות אלפי שורות (מתעדכן)

### 3. תיעוד (docs/)

**מטרה**: לספק תיעוד מקיף למשתמשים ומפתחים.

**תוכן**:
- התחלה מהירה
- מדריכי שימוש
- FAQ
- פתרון בעיות
- תיעוד פיתוח

## 🔄 זרימת עבודה

### התקנה אוטומטית

```
1. הרצת סקריפט
   ↓
2. גיבוי hosts קיים → hosts_old
   ↓
3. העתקת PornHosts → hosts
   ↓
4. העתקת hosts → /etc/hosts
   ↓
5. סיום
```

### התקנה ידנית

```
1. משתמש מבצע גיבוי ידני
   ↓
2. משתמש מעתיק PornHosts
   ↓
3. משתמש מעתיק ידנית ל-/etc/hosts
```

## 🛠️ החלטות עיצוב

### למה Shell Script?

- **פשטות**: קל להבין ולשנות
- **תאימות**: עובד על כל מערכת Unix-like
- **אין תלויות**: לא דורש התקנות נוספות

### למה קובץ HOSTS?

- **פשטות**: אין צורך באפליקציות מורכבות
- **יעילות**: חסימה ברמת מערכת ההפעלה
- **תאימות**: עובד עם כל יישום

### למה לא VPN/DNS?

- **מטרה**: כלי מקומי פשוט
- **עלות**: אין עלויות תפעול
- **פרטיות**: הכל מקומי, אין שרתים חיצוניים

## 🔒 שיקולי אבטחה

### גיבוי אוטומטי
כל התקנה יוצרת גיבוי כדי לאפשר שחזור מהיר.

### בדיקת הרשאות
הסקריפט דורש הרשאות מנהל (sudo) לשינוי /etc/hosts.

### אין הרצת קוד מרחוק
כל הקוד מקומי ואין הורדות או הרצות מרחוק.
