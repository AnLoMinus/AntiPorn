# ❓ שאלות נפוצות (FAQ)

## 🤔 שאלות כלליות

### מה זה AntiPorn?
AntiPorn הוא כלי המסייע בחסימת אתרי תוכן לא הולם באמצעות שינוי קובץ HOSTS של המערכת.

### איך זה עובד?
הכלי משנה את קובץ HOSTS כך שכל ניסיון גישה לאתרים ברשימה מנותב ל-`0.0.0.0`, מה שמונע את הטעינה שלהם.

### האם זה בטוח?
כן, כל עוד אתה מוריד את המאגר ממקור מהימן ומגבה את קובץ hosts המקורי לפני שינויים.

### האם זה חוקי?
כן, השימוש בכלי זה חוקי. אתה משנה רק את הקבצים המקומיים שלך.

## 🔧 שאלות טכניות

### אילו מערכות הפעלה נתמכות?
- Linux (כל ההפצות העיקריות)
- macOS
- Windows (7, 8, 10, 11)

### האם אני צריך הרשאות מנהל?
כן, כי שינוי קובץ `/etc/hosts` (או `C:\Windows\System32\drivers\etc\hosts`) דורש הרשאות מנהל.

### מה קורה אם אני מסיר את ההתקנה?
פשוט החזר את הגיבוי של hosts המקורי, והכל יחזור לקדמותו.

### כמה אתרים חסומים?
הרשימה מכילה עשרות אלפי אתרים ומתעדכנת מעת לעת.

### איך מוסיפים אתרים חדשים?
ערוך את קובץ `PornHosts` והוסף שורות בפורמט `0.0.0.0 domain.com`.

## 🐛 פתרון בעיות

### האתר עדיין נטען אחרי ההתקנה
1. ודא שההתקנה הצליחה
2. נקה את מטמון ה-DNS:
   ```bash
   sudo dscacheutil -flushcache  # macOS
   sudo systemd-resolve --flush-caches  # Linux
   ```
3. אתחל את המחשב מחדש

### הסקריפט לא עובד
1. ודא שיש הרשאות הרצה: `chmod +x AntiPorn`
2. ודא שיש הרשאות sudo
3. בדוק את הודעות השגיאה בטרמינל

### אני לא יכול לערוך את /etc/hosts
ודא שאתה משתמש ב-sudo/administrator בעת עריכה.
