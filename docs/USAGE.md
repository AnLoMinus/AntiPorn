# 📖 מדריך שימוש (Usage Guide)

מדריך מפורט לשימוש בכלי AntiPorn.

## 🎯 מטרות הפרויקט

AntiPorn נועד לסייע ב:
- חסימת גישה לאתרי תוכן לא הולם
- יצירת סביבת עבודה בטוחה יותר
- סיוע בהתמודדות עם התמכרות

## 🔧 שימוש בסקריפט

### תפריט ראשי

כאשר מריצים את `./AntiPorn`, תקבל תפריט עם האפשרויות הבאות:

```
[a] Auto Install AntiPorn
[1] Backup old Hosts to hosts_old
[2] Rename PornHosts to hosts
[3] Replace & Install
[4] About us
[x] Exit
```

### אפשרויות

#### [a] התקנה אוטומטית
מבצע את כל השלבים אוטומטית:
- גיבוי hosts קיים
- העתקת רשימת החסימה
- החלפת hosts

#### [1] גיבוי ידני
גובה את קובץ hosts הקיים ל-`hosts_old`.

#### [2] שינוי שם
משנה את שם `PornHosts` ל-`hosts` (לשימוש ידני).

#### [3] התקנה ידנית
מעתיק את `hosts` ל-`/etc/hosts` ומחליף את הקובץ.

#### [4] מידע
מציג מידע על הפרויקט.

```
AntiPorn/

```

## 🔍 בדיקת חסימה

לבדוק אם אתר חסום:
```bash
ping example-porn-site.com
```

אם אתה מקבל `0.0.0.0`, האתר חסום בהצלחה.

## 🔄 עדכון רשימת חסימה

1. הורד את הגרסה העדכנית:
```bash
git pull origin main
```

2. הסר את ההתקנה הישנה:
```bash
sudo cp /etc/hosts_old /etc/hosts
```

3. התקן מחדש:
```bash
./AntiPorn
```

## ⚙️ התאמה אישית

### הוספת אתרים

ערוך את `PornHosts` והוסף שורות בפורמט:
```
0.0.0.0 example-site.com
0.0.0.0 www.example-site.com
```

### הסרת אתרים

ערוך את `/etc/hosts` והסר את השורות המתאימות.

## 📱 שימוש בסביבות שונות

### דפדפנים
החסימה עובדת בכל הדפדפנים שכן היא ברמת מערכת ההפעלה.

### אפליקציות
כל אפליקציה המשתמשת ב-DNS של המערכת תיחסם גם היא.

## 🔐 שיקולי אבטחה

- **גיבוי**: תמיד שמור גיבוי של hosts מקורי
- **מקורות**: השתמש רק במאגרים מהימנים
- **בדיקה**: בדוק את תוכן `PornHosts` לפני התקנה

## 📊 מעקב אחר שימוש

אם תרצה לעקוב אחר ניסיונות גישה חסומים:
```bash
tail -f /var/log/system.log | grep blocked
```
(תלוי במערכת ההפעלה)
