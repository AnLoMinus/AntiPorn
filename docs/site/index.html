Linux & macOS

התקנה אוטומטית

  1. שכפלו את המאגר: git clone https://github.com/AnLoMinus/AntiPorn.git
  2. הריצו: chmod +x AntiPorn && ./AntiPorn
  3. בחרו באפשרות [a] להתקנה אוטומטית.
למדריך המלא
🪟

Windows

עריכת hosts ידנית

  1. פתחו את Notepad כמנהל.
  2. ערכו את C:\\Windows\\System32\\drivers\\etc\\hosts.
  3. הוסיפו את תוכן הקובץ PornHosts ושמרו.
